Job Description
 Develop and maintain analytical solutions, dashboards and reports to support informed business decisions.
Translate stakeholder business needs into technical specifications and BI standards.
Develop, deploy and maintain Power BI cubes, data models and database queries, and optimise them for performance.
Perform advanced data modelling, data collection and analysis from primary and secondary sources.
Identify, analyse and interpret trends and patterns in complex datasets, and turn data into business insight.
Ensure reports are tested; track and resolve defects and issues to closure.
Collaborate with the Digital Core Team and business units on BI project goals, timelines and standardised reporting requirements.
 Requirements
 4 to 6 Years of overall work experience primarily working on Analytics and BI domain preferably in Microsoft stack (MSBI, PowerBI & Excel). Experience in creating business critical Dashboards and Reports in Power BI using SQL Server, Lakehouse as sources. 
 In depth knowledge of data lake, data warehouse/BI development with a focus on auditability, end-to-end lineage.
 Experience of Dynamics 365 or ERP in comparable role within IT, Finance or Business.
 Technical expertise regarding data models, database design development, data mining and segmentation techniques.
 Must have hands-on experience in Power BI report design, with mandatory expertise in the on-premise Power-BI Report Server with proficiency in DAX and TSQL queries, along with their integration with cloud services.
 Experienced in Data warehousing and Dimensional modelling (Star schema and Snowflake schema).
 Experienced in maintaining and customizing Cubes using SQL Server Analysis Services (SSAS) and experienced in Data visualization/reporting tools like SSRS and Power BI.
 Experience in creating Power BI Reports using various sources like Excel, CSV, SQL Server, Oracle, SQL Server Analysis service (SSAS), Azure SQL, Azure Data Warehouse, etc.,
 Experience in creating complex calculations and measures for Visuals and KPI’s using DAX.
 Experience in Azure Cloud Services, Azure Databricks, Azure DevOps, Azure Storage, Azure Data Lake added value
 Education
 Bachelor Degree or Masters in Computer Science/Engineering/Applications or related field. 
 Certification in Business Analysis is an advantage.
 Microsoft Azure-related training/certifications are an advantage: Data Scientist Associate (DP-100), Power BI Data Analyst Associate (PL-300) or equivalent of other major cloud platforms

 In-depth knowledge in SQL Server, SSAS, SSIS and SSRS; SQL database administration experience is added advantage. 
 Knowledge in Microsoft Dynamics 365 architecture.
 Knowledge in PowerBI report/dashboard designing and publishing.
 Expertise in writing complex SQL queries and optimizing the Performance of Power BI Reports. Designed and created databases, tables, views, stored procedures, and functions using SQL server
