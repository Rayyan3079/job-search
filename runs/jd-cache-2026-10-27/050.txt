We are hiring for an exciting Senior Oracle PL/SQL Developer opportunity. We are looking for a technically strong professional with expertise in Oracle 19c, advanced PL/SQL development, SQL performance tuning, UNIX/Linux shell scripting, and Liquibase.
In this role, you will develop and optimize database solutions, automate deployment processes, and support reliable database operations across multiple environments. This is an excellent opportunity to work on complex, business-critical systems within a global technology environment. This is a Hybrid onsite work opportunity in Serisuri, Chennai.
 Your tasks 
 Designing and maintaining complex PL/SQL packages, procedures, functions, triggers, and database objects
 Optimizing SQL queries and enhancing database performance using execution plans, indexing, and tuning techniques
 Developing UNIX/Linux shell scripts to automate database operations and deployment activities
 Managing database schema changes, version control, and deployments using Liquibase
 Troubleshooting production issues, performing root cause analysis, and supporting releases across development, QA, UAT, and production environments
 Collaborating with development teams, conducting code reviews, and ensuring adherence to coding standards
 Participating in Agile ceremonies, sprint planning, and continuous improvement initiatives
 Requirements
 Minimum 6 years of hands-on experience in Oracle Database development
 Strong expertise in Oracle 19c and PL/SQL programming
 Advanced SQL knowledge, including packages, procedures, functions, triggers, cursors, collections, and exception handling
 Knowledge of Oracle TimesTen
 Strong SQL performance tuning and query optimization skills
 Proficiency in UNIX/Linux shell scripting
 Hands-on experience with Liquibase for database change management and deployments
 Experience with Git or other version control systems
 Strong understanding of database design, data modeling, debugging, and production support
 Fluent English communication skills (minimum B2 level)
