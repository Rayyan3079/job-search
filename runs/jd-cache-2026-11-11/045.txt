 Job Summary
 Responsible for developing and deploying machine learning algorithms. Evaluates accuracy and functionality of machine learning algorithms. Translates application requirements into machine learning problem statements. Analyzes and evaluates solutions both internally generated as well as third party supplied. Develops novel ways to use machine learning to solve problems and discover new products. Has in-depth experience, knowledge and skills in own discipline. Usually determines own work priorities. Acts as resource for colleagues with less experience.
 Job Description
 Role Overview:
 We are seeking a Machine Learning Engineer who can independently deliver ML features and own components of production ML systems. This role emphasizes end-to-end ownership, sound technical judgment, and collaboration across teams.
 Responsibilities
 Design, build, deploy, and operate machine learning features and services end-to-end.
 Own ML pipelines and model behavior from experimentation through production monitoring.
 Solve complex ML and system-level problems independently.
 Participate in technical design discussions and influence implementation decisions.
 Improve performance, reliability, scalability, and cost efficiency of ML systems.
 Collaborate with cross-functional partners to translate product requirements into ML solutions.
 Design, build, and own LLM-based features, including prompt strategies, evaluation pipelines, chatbots, or agent workflows.
 Select and apply LLM frameworks (e.g., LangChain, LlamaIndex) and agent frameworks (e.g., OpenAI SDK, ADK, Autogen) based on use-case requirements and tradeoffs.
 Qualifications
 Strong foundations in data structures, algorithms, and statistics.
 Experience building, deploying, and operating production ML systems.
 Proficiency in at least one ML or deep learning framework.
 Ability to translate ambiguous requirements into concrete technical solutions.
 Strong communication and collaboration skills.
