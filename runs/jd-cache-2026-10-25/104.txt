A Day in Your Life at Atotech Deutschland GmbH & Co. KG 
 As a Working Student (m/f/d) Data Scientist and Programmer, you will partner with R&D engineers and internal stakeholders to develop a user-friendly desktop graphical user interface for FASET, an existing statistical analysis backend for copper surface facet evaluation. You will integrate existing C/C++ functionality into an application and support efficient, reproducible analysis, visualization, data handling, and export. In this role, you will report to the responsible manager within R&D Electronics.
 You Will Make an Impact By 
 Analyzing the existing C/C++ FASET core code and integrating it into a desktop GUI
 Translating user requirements into functional specifications and intuitive software workflows
 Developing and testing front-end functions for parameter input, image visualization, mapping, optimization, and results review
 Implementing asynchronous program execution, project data management, metadata handling, logging, configuration, and file handling
 Improving the performance of computationally intensive analysis and coordinate-mapping functions
 Creating clean, maintainable, version-controlled, and well-documented code
 Skills You Bring 
 Enrolled student (m/f/d) in computer science, data science, or a comparable technical degree program
 Programming knowledge
 Basic experience with graphical user interfaces
 Understanding of software development, testing, debugging, and version control
 Analytical thinking and the ability to understand scientific or engineering workflows
 Good written and spoken English; German skills are beneficial
 Preferred Skills 
 experiences in programming
 Physical Demands and Working Conditions 
 Regular use of standard office and computer equipment
 Ability to communicate technical information clearly and accurately
