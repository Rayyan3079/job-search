About NCR Atleos
 NCR Atleos, headquartered in Atlanta, is a leader in expanding financial access. Our dedicated 20,000 employees optimize the branch, improve operational efficiency and maximize self-service availability for financial institutions and retailers across the globe.
 Job Summary
 We are seeking a highly skilled Database (Oracle and/or Postgress) DBA & PL/SQL Developer to join our Professional Services team supporting mission-critical EFT Switch and Payment Processing platforms.
 This Is a Hybrid Role With Equal Responsibility For
 Database Administration (40%)
 PL/SQL(pgSQL) Development (60%)
 The ideal candidate will have strong experience managing databases while also developing high-performance PL/SQL solutions.
Prior exposure to EFT Switching applications such as Authentic, Base24, Postilion, IST Switch, or similar payment platforms is highly desirable.
 Key Responsibilities
 Database Administration (80%)
 Install, configure, upgrade, and maintain Oracle 11g/12c/19c databases. 
 Manage RAC, Data Guard, RMAN Backup & Recovery environments. 
 Monitor database performance using OEM, AWR, ASH, and ADDM reports. 
 Perform database patching, upgrades, and security hardening. 
 Manage users, roles, schemas, privileges, and tablespaces. 
 Implement backup, recovery, and disaster recovery procedures. 
 Conduct performance tuning and capacity planning. 
 Troubleshoot production database issues and support critical incidents. 
 PL/SQL(pgSQL) Development (20%)
 Design and develop packages, procedures, functions, triggers, and views. 
 Write and optimize complex SQL queries for high-volume transaction systems. 
 Support payment transaction processing workflows. 
 Develop database interfaces and backend business logic. 
 Perform SQL performance tuning. 
 Create data migration and ETL scripts. 
 Conduct code reviews and maintain technical documentation. 
 Support QA, UAT, and production releases. 
 EFT Switch & Payment Processing
 Support database components of EFT Switch and payment applications. 
 Analyze transaction failures and reconciliation issues. 
 Maintain transaction routing and configuration tables. 
 Support settlement and authorization processing. 
 Work closely with application support teams and clients. 
 Participate in supporting client implementations and production deployments. 
 Required Qualifications
 Core Database Skills
 4+ years of DBA experience. 
 Strong experience with Oracle and/or Postgress
 HA & Replication tools
 RMAN Backup & Recovery. 
 Database Monitoring. 
 Database Performance Tuning. 
 Development Skills
 Advanced PL/SQL (pgSQL) development. 
 Stored Procedures. 
 Packages. 
 Triggers. 
 Functions. 
 Complex SQL Query Development. 
 Query Optimization. 
 Payment Domain
 Experience supporting & implementing EFT Switch or payment processing systems. 
 Nice to Have
 Authentic Switch. 
 Base24. 
 Postilion. 
 IST Switch. 
 ISO 8583. 
 UPI/NPCI. 
 PostgreSQL exposure. 
 Liquibase/Flyway. 
 Shell scripting (Bash). 
 Preferred Candidate Profile
 We are looking for candidates currently working as:
 DBA & PL/SQL Developer
 Senior DB Developer with DBA responsibilities
 DB Production Support Engineer
