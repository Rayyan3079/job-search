We are seeking a skilled Data Engineer to design, develop, and maintain scalable data solutions. The ideal candidate will have strong expertise in Microsoft SQL Server technologies (SSMS, SSRS, SSIS) and analytical tool SAS, with a proven ability to manage large datasets, optimize performance, and support business intelligence reporting.
The Intact Data and Analytics team supports the business' data and reporting needs using a hub-spoke model. The selected candidate will be expected to provide technical development skills to build ETL pipelines and effectively
The Data Engineer will report to the Head of DataOps.
 Key Responsibilities
 Design, develop, and maintain data pipelines and ETL processes using SQL Server and SAS
 Write, optimize, and troubleshoot complex SQL queries, stored procedures, and functions in SSMS
 Develop and maintain SSRS reports, dashboards, and data visualizations
 Ensure data accuracy, integrity, and consistency across systems
 Manage and tune SQL Server databases for performance and scalability
 Collaborate with business stakeholders to translate requirements into data solutions
 Perform data analysis and validation to support reporting and decision-making
 Monitor and resolve data-related issues and system bottlenecks
 Requirements 
 Minimum 3 to 5 years' experience in a similar role
 Advanced SQL and Data Bricks experience is compulsory
 Experience working in a regulatory environment is strongly preferred
 Strong hands-on experience with:
 Microsoft SQL Server
 SQL Server Management Studio (SSMS)
 SQL Server Reporting Services (SSRS)
 SAS (Base or EG SAS / SAS Programming)
 Proficiency in SQL scripting, query optimization, and database design
 Experience in ETL development and data integration
 Solid understanding of data warehousing concepts
 Ability to handle large datasets and performance tuning
 Strong analytical and problem-solving skills
 Experience with Power BI or other BI tools
 Exposure to Azure Data Services (e.g., Azure SQL)
 Knowledge of Python or other scripting languages
 Familiarity with data governance and security practices.
 Bachelor's degree in computer science, Data Engineering, Information Systems, or related field
 Relevant certifications in Microsoft SQL Server or SAS (preferred)
